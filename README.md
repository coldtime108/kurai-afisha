# Курай — афиша культуры Башкортостана

Независимый проект о культуре республики. Не является официальным сервисом Министерства культуры Республики Башкортостан.

[Выступление на чекпоинте: текст на 5–7 минут, порядок показа и ответы на вопросы](docs/CHECKPOINT.md).

**Целевой уровень по ТЗ: 4 «Контур». Сейчас работают каталог, подписки, редактор, Telegram, ИИ-помощник NVIDIA и планировщик дня.** [Открыть бота](https://t.me/kurai_afisha_rb_bot). Полные уровни 1–4 ещё не заявляются выполненными. [План](docs/PLAN.md) · [Архитектура](docs/ARCHITECTURE.md) · [Дизайн](docs/DESIGN.md) · [ИИ и результаты проверки](docs/ASSISTANT.md).

Работает [сбор пяти источников с охватом 13 городов](docs/COLLECTION.md): обновление по расписанию, исходный HTML, черновики, предложения правок и раздел в кабинете модератора. Собственные ограничения количества запросов ИИ сняты по просьбе пользователя; ограничения провайдера могут сохраняться.

Добавлен [планировщик «Выходной день»](docs/PLANNER.md): 2–4 события, окно времени, возраст, стоимость на группу, переезды по оценке пользователя и объяснения несовместимых условий. Доступен на сайте, командой `/plan` и через ИИ. Живой проход Telegram подтверждён пользователем.

Обновлены [страницы «О проекте» и «Организаторам», фон по всей высоте, короткие тексты Telegram и автоматический охват городов](docs/UI-COLLECTION-POLISH.md). Пользователь подтвердил оформление.

## Что работает

- Адаптивный каталог: название, город, категория, площадка, период, бюджет на билет, возраст, бесплатный вход, сортировка и пагинация. Фильтры сохраняются в URL.
- Постоянная карточка с источниками; неизвестные значения явно отмечены. Избранное хранится на устройстве.
- Импорт CSV/JSON с валидацией строк и отчётом, отдельные сырые записи, идемпотентность, объединение источников. Конфликт сведений из второго источника отправляет карточку в черновик.
- Закрытый `/admin`: импорт, смена статуса, обращения и журнал. Черновики не доступны публично. Отменённые скрыты из поиска и доступны по UUID с баннером.
- REST API, OpenAPI 3.1, документация без внешних CDN, ETag, request ID, базовые метрики и ограничения частоты.
- `/widget` для iframe с фильтрами, без сторонних cookies.

## Новое в v0.2

- Fira Sans с кириллицей и башкирскими буквами, локальная поставка шрифта, более крупный текст и спокойные заголовки по визуальному ориентиру пользователя.
- Веб-подписка на город/категорию: явное подтверждение, случайный ключ устройства, изоляция владельцев и удаление данных при отписке.
- Ручной редактор событий с проверкой версии, сохранением UUID при переносе и защитой от тихой перезаписи импортом.
- Живой Telegram-worker: меню, общий поиск, карточки, пагинация, подтверждения, отписка, обращения и очередь ежедневных дайджестов. Пользователь подтвердил старт, афишу и карточку в Telegram. Процесс пока работает локально; настоящая доставка ежедневного дайджеста ещё не подтверждена. [Инструкция Telegram](docs/TELEGRAM.md).

## ИИ-помощник

На сайте и в Telegram подключён Nemotron 3.5 Super VL через NVIDIA: шесть инструментов ТЗ и планировщик `plan_day`, память шести пар реплик, уточнения, объяснения и источники из БД, отдельные подтверждения и обычный поиск при сбое модели. Ключ хранится только в окружении сервера. [Устройство, настройка, стоимость и ограничения](docs/ASSISTANT.md).

Контрольный прогон: **20/20 запросов**, p95 **3,36 с**, **60 647 токенов**, **0 ₽** при бесплатном прототипном доступе. Это развивающий набор на 12 сеансах, не независимая приёмка 60+10 и не проверка нагрузки. Визуальная проверка нового блока ещё не завершена.

## Данные

В основном наборе и трёх дополнениях — **44 опубликованных реальных сеанса в 13 городах**: Уфа, Стерлитамак, Нефтекамск, Октябрьский, Янаул, Белебей, Мелеуз, Ишимбай, Бирск, Салават, Туймазы, Кумертау и Сибай. Новый [региональный пакет из 30 сеансов](data/reviewed-events-regions.json) сверен по доступным карточкам учреждений и организаторов, [основания полей](data/reviews/regions-2026-11-14.json) сохранены отдельно. В локальной базе также 21 черновик сборщика. Это не полный охват республики и не набор заказчика. Автоматический сбор теперь обслуживает пять источников и выбранные площадки всех 13 городов; часть карточек других сайтов по-прежнему сверяется вручную. [Состав, источники и проверки](docs/REGIONS.md).

У «Макбета» театр и билетная страница сведены в одну карточку. Исходные HTML хранятся в закрытой БД семь дней; творческие описания и фотографии в публичный набор не копируются. Иллюстрация главной создана с помощью ИИ.

Даты не переносятся на выдуманное будущее. API возвращает UTC, интерфейс — время Башкортостана (UTC+5). Неизвестные цена/возраст не проходят соответствующий фильтр. В каталоге бюджет сравнивается с нижней границей одного билета. Планировщик отдельно рассчитывает группу; строгий бюджет требует известной верхней суммы. Наличие мест и скидки не предполагаются.

## Docker

Нужны Docker Engine / Docker Desktop с Linux-контейнерами и Compose. Из корня репозитория:

```sh
docker compose up --build
```

Открыть `http://localhost:8000`. Запускаются PostgreSQL 16, миграции, повторяемая загрузка данных и сервер с собранным React-интерфейсом. Порт опубликован только на локальном компьютере.

Для модерации задайте длинный случайный `ADMIN_TOKEN` в `.env` по образцу `.env.example`, перезапустите приложение и введите ключ на `/admin`. Ключ остаётся в памяти страницы. Без ключа административные операции отключены. Перед публичным развёртыванием замените демонстрационный пароль БД. В данной Compose-конфигурации пароль должен состоять из букв/цифр; другие символы требуют URL-кодирования в DATABASE_URL.

**Проверка Docker:** конфигурация Compose корректна; сборка/запуск на чистой машине и порог 10 минут ещё не проверены — Docker Engine в текущем окружении не запущен.

## Разработка без Docker

Python 3.12+, Node.js 22+, pnpm 11.25.0. Локально используется SQLite, целевой контур — PostgreSQL. PowerShell, из корня:

```powershell
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements-dev.txt -c requirements-lock.txt
$env:PYTHONPATH='backend'
.venv/Scripts/python -m alembic upgrade head
.venv/Scripts/python -m kurai.seed
pnpm --dir frontend install --frozen-lockfile
pnpm --dir frontend build
.venv/Scripts/python -m uvicorn kurai.main:app --host 127.0.0.1 --port 8000 --no-access-log
```

Vite с горячим обновлением: `pnpm --dir frontend dev`, при запущенном API на 8000. На Linux/macOS используйте `.venv/bin/python` и `export PYTHONPATH=backend`.

Для текущей локальной базы Windows: `scripts/start-web.ps1` открывает сайт на `http://127.0.0.1:8001`; `scripts/start-telegram.ps1` запускает единственный worker. Скрипты читают `.env`. Настройки ИИ — `LLM_ENABLED`, `LLM_MODEL`, `NVIDIA_API_KEY` по `.env.example`.

Локальные копирование SQLite и восстановление в отдельный файл проверены: совпадают все таблицы и логический хэш. [Команда запуска, отчёт и границы проверки](docs/OPERATIONS.md). Рабочая БД не заменялась; PostgreSQL и переключение процессов остаются отдельными проверками.

## Проверки

```powershell
.venv/Scripts/python -m pytest
pnpm --dir frontend build
docker compose config --quiet
```

В репозитории 94 автоматических проверки с изолированными БД и миграциями. На этапе страниц, Telegram и охвата сбора прошли двадцать четыре разные целевые проверки, TypeScript, сборка и короткие живые HTTP-сценарии; весь набор повторно не прогонялся. [Результаты планировщика](docs/PLANNER.md), [ИИ](docs/ASSISTANT.md) и [сбора](docs/COLLECTION.md). Синтетические события существуют только в тестовой БД; реальные подписки тестами не затрагиваются.

Отдельно добавлен [воспроизводимый набор из 34 запросов](data/evaluation/search-baseline.json) к API и контроллеру бота. Прогон: `python -m kurai.evaluate --output work/search-baseline.json` при `PYTHONPATH=backend`. [Результаты и границы измерений](docs/LEVEL2-PROGRESS.md). Это базовый поиск на семи сеансах, не итоговая оценка агента.

При ограничениях на системный временный каталог создайте `work/` и запустите `pytest --basetemp=work/pytest-local`. Не используйте производственную БД для тестов.

- `/api/docs` — примеры; `/api/openapi.json` — контракт OpenAPI 3.1.

## Безопасность и известные ограничения

Админ-ключ передаётся в Authorization, не в URL. В логах — шаблон маршрута, request ID, код и задержка; без параметров поиска, текстов обращений, IP и ключей. Стандартный access log Uvicorn отключён. Описания выводятся как текст; исполнительных полномочий у внешнего текста нет.

Лимиты в памяти подходят для одного процесса; перед масштабированием нужно общее хранилище. Обращения старше 30 дней, истёкшие подписки и диалоги очищаются при обращении к сервису и фоновым заданием API каждый час. Подписка хранится до 180 дней, состояние бота — до 24 часов. Избранное не отправляется на сервер.

Модель NVIDIA подключена через бесплатный прототипный endpoint: стоимость диалога 0 ₽ при текущем бесплатном доступе, токены учитываются по `usage`. Платный запасной провайдер не подключается. [Расчёт, лимиты и приватность](docs/ASSISTANT.md). Секреты не входят в Git или браузерную сборку. TLS, восстановление резервной копии и постоянный запуск проверяются на целевом хосте.
