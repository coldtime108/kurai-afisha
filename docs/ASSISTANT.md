# ИИ-помощник: реализация и проверка

14 ноября 2026 подключена `nvidia/nemotron-3.5-super-vl-120b-a12b` через бесплатный прототипный endpoint NVIDIA. Общий `AssistantService` используется FastAPI и Telegram-контроллером. Это промежуточная реализация третьего уровня, без объявления итоговой приёмки.

## Действия и факты

Модель выбирает типизированное действие и его аргументы. Пользователь не видит её свободный текст или рассуждения. Названия, даты, цены, возраст, статусы, источники и объяснения формируются из БД и проверенных фильтров. Неизвестная цена или возраст исключают событие из соответствующего поиска. Бюджет означает нижнюю границу цены одного билета, без гарантии наличия мест.

| Инструмент | Поведение сервера |
|---|---|
| `search_events` | Изменение текущих фильтров; до трёх опубликованных карточек, количество и предложения для пустой выдачи |
| `get_event` | UUID только из последней показанной подборки; отмена явно отмечается, черновик недоступен |
| `find_similar` | Другие события той же категории с текущими ограничениями; объяснимая эвристика без векторной модели |
| `get_venue_schedule` | Поиск по точному названию площадки и периоду |
| `subscribe` | Предложение подписки; сохранение только отдельной кнопкой подтверждения владельца |
| `save_feedback` | Предложение отправки пользовательского текста модератору; запись только после подтверждения |

Внутренний `ask_clarification` выбирает один вопрос: город, дата, возраст, местоположение, ссылка на событие или границы помощи. Геолокация и расчёт расстояний не подключены. Пустую выдачу и карточки формирует код. Явные ограничения, распознанные правилами, имеют приоритет над догадками модели; слово категории не дублируется в поиске по названию. Возраст 0 не подставляется вместо неизвестного возраста.

## Память, подтверждения и данные

- Последние шесть пар «запрос–ответ»; диалог, включая фильтры, истекает через 24 часа от начала, даже если остаётся активным. Относительные даты считаются от серверной даты Башкортостана, карточки показывают UTC+5.
- Веб использует случайный 256-битный ключ устройства, общий с веб-подпиской; в БД хранится хэш. Telegram имеет отдельное пространство владельцев. Чужое подтверждение не выполняется.
- Токен действия одноразовый, срок — десять минут. Новое сообщение отменяет прежнее предложение; слово «да» не выполняет запись. Модель не получает ключ, Telegram ID или параметр `confirmed`.
- Запрос и ограниченная история передаются NVIDIA. Интерфейс и `/start` предупреждают об этом. Не следует вводить личные данные и ключи. Распространённые форматы токенов, телефонов и email маскируются; это не универсальный детектор персональных данных.
- Трассы доступны только модератору: версия промпта, очищенный запрос, инструменты и аргументы, фильтры, ID результата, задержка, токены, причина резервного режима и расчёт стоимости. Аргумент текста обращения заменяется длиной и хэшем; его запрос в диагностике скрывается.
- Фоновая очистка удаляет трассы старше семи дней и неактивные диалоги. «Новый диалог» и `/new` удаляют свой диалог и трассы сразу. Отписка Telegram также удаляет приватное состояние.

## Лимиты и стоимость

`reasoning_effort=none`, максимум 768 выходных токенов на вызов, без параллельных инструментов. Верхний предел — пять инструментов на ответ; неверные аргументы допускают одну попытку исправления. Обычно выполняется один запрос модели и один инструмент. Бюджет работы модели — восемь секунд; отдельный сетевой вызов отменяется не позже семи секунд. Сбой, таймаут, 429, неверный ответ, отключение и исчерпание лимита включают явно подписанный обычный поиск.

По просьбе пользователя 14 ноября **сняты собственные ограничения частоты и суточной квоты ИИ** — на сайте и в Telegram. Счётчики запросов и токенов сохранены для наблюдения, но по умолчанию не блокируют диалог. Квоты и доступность самой NVIDIA остаются вне контроля приложения. Сохранены проверка фактов, конечное время обработки и подтверждения действий. Одновременно обрабатывается один запрос конкретного диалога, чтобы сообщения не перемешивались; это не ограничение количества запросов. Блокировки рассчитаны на один API-процесс и один worker.

**Стоимость диалога — 0 ₽ при бесплатном прототипном доступе NVIDIA.** Расчёт: сумма входных и выходных токенов каждого вызова × тариф 0 ₽. Токены учитываются отдельно, бесплатность не отменяет квоты. Платный запасной провайдер не подключается. Доступность и квоты могут меняться: [описание сервиса NVIDIA](https://docs.api.nvidia.com/nim/docs/product). Параметры модели: [официальная справка](https://docs.api.nvidia.com/nim/reference/nvidia-nemotron-3_5-super-vl-120b-a12b-infer).

## Настройка и API

В локальном `.env`, исключённом из Git:

```dotenv
LLM_ENABLED=true
LLM_MODEL=nvidia/nemotron-3.5-super-vl-120b-a12b
NVIDIA_API_KEY=ваш_локальный_ключ
```

Windows: `scripts/start-web.ps1` и, отдельно, `scripts/start-telegram.ps1`. Скрипты читают необходимые переменные из `.env`; сами модули Python получают окружение процесса. Compose передаёт настройки обоим сервисам. `LLM_ENABLED=false` оставляет обычный поиск. После изменения настроек нужен перезапуск.

Оба клиента учитывают существующие сетевые настройки. `SystemNetworkSession` добавляет aiogram `trust_env=True`: без этого в текущем окружении прямое соединение Telegram завершалось таймаутом. Системные настройки не изменяются; новые зависимости не добавлялись.

Схемы доступны в `/api/openapi.json`:

- `GET /api/v1/assistant/status` — конфигурация и уведомление о данных; не гарантия доступности провайдера.
- `POST /api/v1/assistant/messages` — `{ "message": "..." }`.
- `POST /api/v1/assistant/confirm` — `{ "token": "...", "accept": true }`.
- `DELETE /api/v1/assistant/dialog` — удалить свой диалог и диагностику.
- `GET /api/v1/admin/assistant/traces` — последние 100 трасс, только с ключом модератора.

Пользовательские методы требуют `Authorization: Bearer <ключ устройства>`. Ответ: `request_id`, режим, сообщение, карточки с причинами, фактические фильтры, количество, предложения и необязательное подтверждение. Приватные ответы имеют `Cache-Control: no-store`. Публичного чтения чужой истории нет.

## Проверки и границы результата

**73 автоматические проверки** проекта охватывают миграцию 0004, владение, подтверждения, отмену/истечение, шесть ходов, неизвестные ID, неверные аргументы, цену/возраст, пустую выдачу, общий лимит при одновременных запросах, таймауты, 429 и Telegram-контроллер. Последний полный прогон — 71/71; после добавления проверки модерации во время ответа и кнопки Telegram — 32/32 затронутых теста, включая оба новых. Внешний API в автоматических тестах подставной.

Отдельно выполнены **20 живых контрольных запросов: 20/20**, p95 **3359 мс**, **60 647** учтённых токенов, **0 ₽**; неподтверждённых записей подписок и обращений — **0**. [Отчёт](reports/assistant-smoke-2026-11-14.json) и [запросы с ожиданиями](../data/evaluation/assistant-smoke.json). Промежуточные прогоны выявили лишнее слово категории в названии, выдуманный возраст и неуместные вопросы. Набор использовался для доработки, поэтому независимым не считается.

Прогон: `PYTHONPATH=backend`, настройки модели в окружении, `python -m kurai.assistant_evaluate --live --output work/assistant-smoke.json`. Создаётся временная БД из 12 реальных сеансов; время фиксировано: `2026-11-14T04:00:00+00:00`. Отчёт содержит хэши набора и результаты. UUID относятся к временной БД, живые подписки не затрагиваются. Измеряется общий сервис; два случая проходят через Telegram-контроллер, без сети доставки Telegram. Это не HTTP-нагрузка, не p95 эксплуатации и не итоговая приёмка 60+10.

React-сборка и TypeScript прошли. Пользователь подтвердил работу сайта, затем помощника Telegram через новый путь `/start` → «Подобрать с помощником» → «Попробовать пример». Автоматизированная визуальная проверка нового блока на desktop/360 px не завершена: встроенный браузер недоступен чату, управление внешним Firefox остановлено политикой URL. Пользовательский проход и сборка не заменяют полную проверку адаптивности и доступности.

Живой HTTP API отдельно проверен на запросе о спектакле в Стерлитамаке и уточнении «подешевле»: оба ответа в режиме модели вернули «Макбета» и сохранили город/бюджет. Созданный проверкой диалог удалён. Статус события перечитывается после ответа модели: отмена или перевод в черновик во время обработки не оставляют устаревшую карточку в ответе.

Далее: проверка нового интерфейса и доставки ответов Telegram, независимые запросы и метрики ТЗ, сбор двух источников и планировщик. Docker/PostgreSQL, естественный дайджест и постоянное размещение ещё требуют отдельной приёмки.
