# Дизайн: завершение текущего этапа

13 ноября 2026. Доработан существующий интерфейс по просьбе пользователя перед подключением API модели. Ориентиры — его примеры баланса цвета, ранее выбранный характер шрифта и культура Башкортостана. Это отчёт о проверенной версии интерфейса; он не означает завершение ИИ-помощника, сбора данных или размещения на сервере.

## Решения

Сохраняется направление «современная культурная редакция Башкортостана»: Fira Sans, тёплая бумага, глубокие зелёный и синий, курай, авторская иллюстрация. Присланное правило 60/30/10 использовано как ориентир по иерархии. Процент площади цветов не измерялся. Дополнительный яркий цвет не нужен: золотой акцент уже связан с кураем и иллюстрацией.

- Первый экран компактнее: убрано повторное перечисление городов, уменьшены высота и отступы; золотой переход «Найти своё событие» выделен на светлом фоне.
- Категории оформлены как спокойная строка с подчёркнутым выбором. Кнопки категорий и быстрых дат сообщают состояние через `aria-pressed`.
- Применённые город, даты, бюджет, возраст, категория, площадка и текст поиска видны отдельно. Каждое условие снимается собственной кнопкой; общий сброс сохранён.
- Внизу раскрытой формы добавлено применение фильтров. После отправки панель сворачивается, пользователь возвращается к началу каталога.
- Подписи полей, цены, источники, пояснения и нижняя часть страницы стали крупнее. На телефоне поля имеют размер текста 16 px; основные кнопки и поля — не ниже 44 px.
- Подписка получила нейтральную поверхность; пояснение достоверности отделено линиями. Эти блоки меньше конкурируют с событиями.
- На странице события дата, местное время, площадка, цена и переход к организатору собраны в одном блоке. На узком экране он идёт перед описанием. Порядок элементов в документе соответствует мобильному чтению и перемещению клавиатурой.
- Возрастная маркировка, если известна, видна возле названия. Неизвестные сведения по-прежнему отмечаются словами; переход к организатору использует существующую проверенную ссылку.
- На ширине до 740 px первый экран и страница события переходят на одну колонку. Это устраняет тесную композицию и наложение подписи на иллюстрации при 600 px.

Новые пакеты, внешние шрифты, сторонняя аналитика и дополнительные изображения не добавлялись. События и подписки не менялись.

## Проверка

- TypeScript и сборка Vite прошли. После последнего изменения CSS производственная сборка повторно прошла; локальный сайт обновлён.
- В браузере просмотрены широкая версия, 600 px и 360 px. На 600 px документ имеет ширину 585 px, на 360 px — 345 px с учётом полосы прокрутки; горизонтального выхода страницы нет. Горизонтальная прокрутка строки категорий предусмотрена.
- Запрос длиной 192 символа переносится внутри выбранного условия на 360 px. Ширина кнопки и её содержимого — 303 px; страница не расширяется.
- Поиск «Стерлитамак, до 800 ₽, возраст 17» возвращает «Макбета». Удаление отдельного условия сохраняет остальные. Выходные выделяются и задают даты 14–15 ноября 2026.
- Поиск «Стерлитамак, до 1000 ₽, возраст 8» показывает пустое состояние с пояснением. После удаления возраста доступна карточка «Макбета».
- В мобильной версии проверены категория «Театр», сортировка по цене, сохранение и удаление «Макбета» из избранного. Прежнее избранное восстановлено.
- Окно изменения подписки проверено на 360 px: читаемые поля, прокрутка внутри окна, явное подтверждение, заблокированная до согласия кнопка. Escape закрывает окно. Существующая подписка не изменялась.
- Компактная афиша `/widget` на 360 px показывает событие Стерлитамака и не расширяет страницу.
- Проверены клавиатурный фокус на категории, доступные названия избранного и состояний выбора. Полный аудит WCAG не заявляется.

Контраст изменённых пар вычислен по относительной яркости sRGB:

| Пара                                   | Контраст |
| -------------------------------------- | -------: |
| Белый текст на основной зелёной кнопке |   8,44:1 |
| Тёмный текст на золотой кнопке         |   6,74:1 |
| Приглушённый текст на бумажном фоне    |   5,08:1 |
| Приглушённый текст на панели подписки  |   4,72:1 |
| Текст выбранных быстрых дат            |  10,11:1 |
| Подсказки полей на светлой поверхности |   5,39:1 |

Скриншоты сохранены в пользовательской папке `outputs` вне исходников: главная, каталог, страница события, окно подписки и планшетная версия. Серверные алгоритмы в этой итерации не менялись; прежний результат 48 Python-тестов не выдаётся за новый прогон. Изменённые действия проверялись через интерфейс.

## Дальше

Основа текущего дизайна готова к подключению ИИ-помощника. Его диалог, уточнения, объяснения, загрузка, ограничения и резервный обычный поиск будут оформлены в той же системе при реализации API. Для новой функции понадобится отдельная проверка интерфейса.
