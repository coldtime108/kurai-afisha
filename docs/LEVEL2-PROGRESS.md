# Поиск, подписки и публикация: промежуточная проверка

13 ноября 2026. Это отчёт следующей итерации после подключения Telegram, а не итоговая приёмка уровня 2 или 4.

## Изменения

- Добавлено отдельное время публикации `published_at`: старый черновик после публикации может попасть в дайджест. До исправления отбор по `created_at` мог его пропустить. Импорт, ручной редактор и смена статуса используют одинаковое правило. Уточнение уже опубликованного события не делает его новым повторно.
- Миграция 0003 сохраняет первоначальную дату существующих опубликованных карточек и не выдаёт миграцию за поступление новых событий.
- Бот понимает бюджеты с разделителями тысяч, даты `14.11.2026` и `14 ноября`, дополнительные формы категорий и города, добавленные в каталог. Несуществующая дата возвращает понятное сообщение, сохраняя предыдущие фильтры.
- Пустая выдача объясняет также ограничения площадки и бесплатного входа.
- В разделе подписки на сайте появился переход к живому Telegram-боту. Сохранённая категория «все» при повторном открытии формы сохраняется независимо от текущего фильтра каталога.

## Автоматическая проверка

47 тестов прошли на Python 3.12 / SQLite. Среди новых сценариев — публикация старого черновика тремя путями, отсутствие повторного объявления обычной правки, обновление существующей БД, поиск по добавленному городу и безопасность изолированного оценочного прогона.

TypeScript и производственная сборка Vite прошли. В браузере проверены ссылка на бота, сохранение категории «все» при редактировании на фоне выбранного фильтра «Концерты» и ширина 360 px без горизонтального переполнения. Предупреждение библиотеки TestClient о переходе с httpx на httpx2 остаётся известным предупреждением; ошибок тестов оно не вызвало.

## Воспроизводимая базовая оценка поиска

Набор: [34 контрольных запроса](../data/evaluation/search-baseline.json). Исходные данные: семь проверенных реальных сеансов из `data/reviewed-events.json`. Эталонные ответы размечены для этого набора. Дата запросов зафиксирована: 13 ноября 2026, 14:00 по Башкортостану; календарные примеры не зависят от времени повторного запуска.

Запуск из корня с установленными зависимостями разработки:

```powershell
$env:PYTHONPATH='backend'
.venv/Scripts/python.exe -m kurai.evaluate --output work/search-baseline.json
```

Прогон создаёт временную изолированную SQLite БД, применяет миграции и загружает проверенный набор. Даже при заданной внешней `DATABASE_URL` база работающего сайта не используется. Telegram-токен и Telegram API для оценки не нужны.

[Машиночитаемый отчёт](reports/search-baseline-2026-11-13.json) содержит результаты каждого запроса, хеши данных и набора, время прогона и p95.

Это замеры FastAPI TestClient и контроллера бота внутри процесса. Они не измеряют интернет, Telegram, PostgreSQL, внешнюю модель или производственный сервер. Нет независимого скрытого набора, а 34 запроса не заменяют 60+10 для итоговой оценки агента. Нулевая доля повторов по `dedup_key` на семи записях не доказывает качество сведения дублей из большого числа источников.

Полноту обязательных сведений нельзя объявлять достигнутой по одной валидации схемы: цена известна у 4 из 7 сеансов, возраст — у 5 из 7. Неизвестные поля не заполнены догадками. Для окончательного отчёта требуется расширить данные и зафиксировать правила измерения заполненности.

## Живая проверка и открытые пункты

Пользователь проверил подписку на Уфу. Наличие подтверждённой Telegram-подписки проверено в рабочей БД без вывода идентификатора получателя. Старт, афиша и карточка были подтверждены в предыдущей итерации. Настоящая доставка дайджеста в обычное время ещё не подтверждена; это остаётся отдельным пунктом плана.

Перед обновлением создана резервная копия рабочей SQLite через штатный backup API, её целостность проверена. После перехода на 0003 и перезапуска сохранены все семь событий и подтверждённая подписка; сайт и Telegram-worker успешно запущены.

Docker Engine остаётся недоступным в текущем окружении. Реальный Docker/PostgreSQL и запуск на чистой машине до 10 минут не объявляются пройденными. Постоянного сервера и подключённой модели пока нет.
