# Проверка первой контрольной точки

13 ноября 2026 · версия 0.1.0. Это отчёт о текущем этапе разработки, не итоговая приёмка уровня 4.

## Результаты

- 17 интеграционных проверок прошли на Python 3.12 / SQLite с настоящими миграциями. Повторный импорт 100 записей проверен в изолированной БД; синтетические карточки скрыты от выдачи.
- Проверка типов TypeScript и сборка Vite выполнены успешно.
- Конфигурация Compose корректна. PostgreSQL/Docker-запуск пока не проверен: Docker Engine не запущен.
- Локальные HTTP-запросы к `/health`, каталогу и главной возвращают 200. В каталоге семь сеансов.
- В браузере проверены первый экран, категория «Театр», обновление URL, переход к карточке, сохранение в избранное. При ширине 360 px горизонтального переполнения нет.

## Ограничения

Нет живого Telegram-бота, подписок, LLM, автоматического сборщика и планировщика. Проверки «без модели» относятся к независимому каталогу и не подменяют демонстрацию автоматического fallback будущего агента. Нет измерений на целевом хосте, полного набора метрик или 60+10 контрольных запросов. Семь сеансов недостаточно для проверки качества сбора на 50 карточках.

Неизвестные цена и возраст сохранены как null. Механизм отмен и дедупликации проверен на изолированных данных; настоящие события не объявлялись отменёнными ради демонстрации. Переносы и нечёткие дубли требуют следующего этапа.
