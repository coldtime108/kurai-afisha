# Проверка v0.2

13 ноября 2026. Текущий этап: типографика, подписки, ручной редактор и подключение живого Telegram. Это не итоговая приёмка уровня 4.

## Автоматические проверки

39 тестов на Python 3.12 и SQLite с настоящими миграциями 0001 → 0002; последний прогон после подключения Telegram — 39 passed:

- прежние 17 проверок каталога, 100 строк импорта без дублей, отмены, черновики, авторизация, источники, ETag, фильтры, 20 запросов без модели;
- обязательное подтверждение подписки, отсутствие доступа к чужому UUID и фильтрам, обновление без дубликата, удаление и срок хранения;
- создание черновика, редактирование с сохранением UUID, защита от устаревшей версии, перенос даты и журнал, запрет тихой перезаписи импортом;
- регистронезависимый поиск по кириллическим меткам; опечатки в городе, бюджет и относительные даты;
- бот: меню, поиск, карточка, страницы, подтверждение/отмена/повтор nonce, привязка к пользователю, обращение только после подтверждения, отменённые события;
- очередь дайджестов: одна запись в день, только опубликованные события, очистка при отписке, сохранение ошибки доставки для повторной попытки;
- настоящий Dispatcher aiogram с сетевым транспортом-заглушкой: обработка личного чата, игнорирование групп и callback чужого чата; сообщения в Telegram не отправляются.
- настройка профиля: Telegram возвращает команды с привязкой к Bot; сверяются значения команды и описания, а не служебная привязка. Другой username и существующий webhook блокируют изменения. Проверка связи не подтверждает и не удаляет ожидающие обновления.

TypeScript и Vite: сборка проходит. Fira Sans поставляется локально, включая Cyrillic Extended. Конфигурация Compose проверяется отдельно от живого запуска контейнеров.

## Проверка в браузере

Просмотрены обновлённый первый экран и карточки. Пройден сценарий: открыть форму подписки → включить подтверждение → сохранить → увидеть «Ваша афиша · Уфа». До подтверждения кнопка сохранения недоступна. На ширине 360 px документ и область просмотра имеют одинаковую ширину, горизонтального переполнения нет. Скриншоты сохранены отдельно от исходников.

## Границы результата

Подключён [@kurai_afisha_rb_bot](https://t.me/kurai_afisha_rb_bot). Telegram API подтвердил имя бота, сохранение семи команд, описания и возможность polling. Worker запущен с той же `data/runtime/preview.db`, что локальный сайт. Пользователь подтвердил «Начать → Открыть афишу → карточка события»; журнал содержит успешный ответ на сообщение и два ответа на кнопки без ID пользователей и текста запросов. Токен отсутствует в исходниках и хранится в игнорируемом `.env`.

Реальная подписка и естественная доставка ежедневного дайджеста пока не подтверждены пользователем. Их логика покрыта изолированными проверками. Процесс работает на компьютере пользователя; постоянный сервер и автозапуск после перезагрузки ещё не настроены. Инструкция запуска — docs/TELEGRAM.md.

Docker Desktop был запущен командой, но его CLI не вернул готовый Engine; контейнерный запуск PostgreSQL и порог 10 минут остаются непроверенными. SQLite-проверки не подменяют приёмку на PostgreSQL. LLM, сборщик, планировщик и набор 60+10 запросов — следующие этапы. Семь реальных сеансов недостаточно для измерения качества сбора на 50 карточках.
